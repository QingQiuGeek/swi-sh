# 汽车保险网站 禁止清单

> 版本：v0.1
> 上游：`prd.md` v0.6、`visual.md` v0.1、`design.md` v0.1、`ui-patterns.md` v0.1、`page-specs.md` v0.1
> 本文回答**「什么不要做」**。所有条目都是明确取舍的结果，不是风格偏好；实现阶段任一条被违反即视为未完成。
> 与上游文档冲突时，以本文为准。

---

## 1. 禁止的视觉风格

- **科技暗黑风 / 大屏数据可视化风**：不做发光边框、网格底纹、扫描线、粒子光效。
- **玻璃拟态与霓虹渐变**：不使用 `backdrop-blur` 造磨砂卡片、不做渐变文字、不做彩色发光阴影。
- **深色主题**：本期只做浅色。页面永不渲染 `.dark`，也不跟随系统深色偏好（`globals.css` 的 `@custom-variant dark` 只用来把 shadcn 源码里的 `dark:` 变成惰性样式）。
- **促销式视觉**：不用红黄撞色、不用「限时抢购」角标、不用倒计时、不用满屏浮动的「立即报价」气泡。
- **卡通插画与吉祥物**：不使用吉祥物、表情包式插画、3D 汽车模型大图。
- **重度拟物与厚阴影**：只用 `--shadow-xs / sm / md` 三档，不为卡片叠加多层阴影。
- **超粗字重**：字重上限 700，不使用 800 / 900 的「震撼标题」。

---

## 2. UI 反模式

- **实心按钮成灾**：分区级 / 页面级主行动点每屏最多一个；产品卡片为例外——允许一处实心「立即投保」（同一张卡片不得出现第二个实心按钮），其余操作一律降级为 `outline` 或文字链接。
- **只靠颜色传达信息**：订单状态必须「颜色 + 文字」；材料必需性必须「颜色 + 文字」；表单错误必须「红字 + 文字说明」。
- **用占位图冒充真实素材**：本项目没有真实摄影，产品卡片用类别图标 + 浅色底，**不使用**随机图库 URL、`picsum`、`unsplash` 之类的外链图片冒充官方配图。
- **造真实机构信息**：不出现真实保险公司名称、真实牌照号、真实费率表、真实地址电话；全部用字典里的占位内容并标注「演示数据」。
- **把关键信息藏在交互后面**：价格、保额、服务内容必须首屏或卡片上直接可见，不允许「点击查看价格」「填写手机号后查看报价」。
- **裸 HTML 表单控件**：`input` / `select` / `textarea` / `dialog` 一律走 `components/ui/` 下的 shadcn 组件，不手写原生控件样式。
- **遮罩组件缺标题**：`Dialog` / `Sheet` / `AlertDialog` 必须带 `Title`，否则屏幕阅读器读不出上下文。
- **手写 `z-index`**：遮罩层级交由组件内部处理，页面里不出现 `z-[999]` 这类魔法数字（Header 的 `z-40`、ScrollRail 的 `z-20` 是骨架固定层级，不在此列）。

---

## 3. 组件反模式

- **`components/ui/` 里写业务**：不出现业务文案、不发请求、不 import `lib/server`、不读 store。这一层必须能整目录复制到另一个项目。
- **Block 自己取数**：`components/blocks/` 不发请求、不查字典，数据与文案由页面传入。
- **Block 只写「正常态」**：loading / empty / error / ready 四态要么齐全，要么明确说明缺哪一态。
- **`'use client'` 上浮**：不加在 `page.tsx` 上，不加在 `components/sections/` 上。只有真正需要交互的叶子节点才标。
- **一个组件两种数据源**：桌面表格与移动卡片必须共用同一份 props 与同一套筛选状态，不允许各写一份取数或过滤逻辑。
- **用 `Tabs` 做导航**：个人中心四个 Tab 是路由，不是页内切换，必须用 `next/link`。
- **把 `Tabs` 当路由**：反之，订单列表的「全部 / 待支付 / 已生效」是页内过滤，不允许改成三个路由。
- **原生 `<a href>` 做站内跳转**：全站导航统一 `next/link`。
- **列表 `key` 用下标**：一律用业务 id（`product.id`、`order.id`、`step.id`）。

---

## 4. 布局反模式

- **各页面自写容器**：最大宽度与左右内边距统一由 `Container` 负责，页面与分区不写 `max-w-*` / `px-*` 的替代实现。
- **分区之间加分割线或色块硬切**：分区靠垂直留白切换。
- **各分区抬头长得不一样**：眉标 → 大标题（可第二行换色）→ 副标题，五个分区与内容页共用同一套 `SectionHeading`。
- **产品卡片分组标题**：6 款产品按类别分组的组内数量是 1 / 3 / 2，分组只会割裂视觉；类别以卡片标签呈现。
- **给 6 条数据做筛选与分页**：产品列表不加分类筛选、不加分页、不加「加载更多」。
- **移动端出现横向滚动条**：360px 宽度下必须无横向溢出；长 UUID 允许折行，不允许撑破容器。
- **移动端保留桌面级装饰**：ScrollRail 在 < 1024px、悬浮工具轨在 < 1280px 不渲染（1024–1279px 时内容区右缘与轨道重叠，宁可不显示）。
- **错落 / 拼贴 / 不对称的编辑式排版**：卡片高度与基线严格对齐。

## 5. 交互反模式

- **hash 路由**：禁止 `#/products` 这类形式；也不要用 `#section` 做分区锚点。跨页分区跳转靠 `sessionStorage` 的 `swi:pending-section`。
- **语言切换新增历史记录**：必须 `router.replace`，且 URL 语言段与 `NEXT_LOCALE` Cookie 同时更新。
- **登录后丢意图**：未登录访问 `/purchase/*`、`/account/*` 不重定向、不清 URL，保留原地址并自动弹出登录框。
- **改动产品数据影响历史订单**：订单里的产品名与价格是下单时的快照，不允许在渲染时回查当前产品价格。
- **视觉特效抢注意力**：不做视差、不做逐字打字机、不做数字滚动跳表、不做自动轮播滑块。动效仅限「渐显 ≤ 200ms」「平滑滚动定位」「悬停过渡 ≤ 150ms」三类。
- **自动播放只有两处，第三处就是错**：① 首页首屏背景视频；② 首页「投保案例」横向轨道。
  - 首屏视频：必须静音 + `loop` + `playsInline`、无播放控件；4.9MB 的视频**不得参与 LCP**——poster（`next/image` + `priority`）先上，视频等窗口 `load` 之后才挂载（`preload="none"`）并在 `onPlaying` 后才淡入；滑出视口暂停解码；`prefers-reduced-motion: reduce` 时完全不挂载 `video`。视频层绝对定位在 Hero 内部，**不是 `fixed`**，滑到下面的分区就滚出视口，不允许做成全局背景。
  - 投保案例轨道：匀速无缝循环（约 80px/秒，卡片循环衔接，不停顿、不回卷），不设播放控件，悬停 / 聚焦停住，`prefers-reduced-motion: reduce` 时不动；不得用「一张一张跳」或「到头跳回起点」的做法冒充轮播。
- **深底文字不验证对比度**：压在视频或深色遮罩上的文字必须实测，任一位置低于 4.5:1 就是不合格。首屏视频用 `brightness(0.6)` + 径向遮罩（中心 `primary/45` → 边缘 `primary/88`）压住背景，文案带最亮处实测 5.6:1（实测方法：把内容层 `visibility: hidden` 后截图，对文字包围盒逐像素算对比度）。
- **深底区域沿用浅底配色**：首页首屏是深底，原本为浅底设计的元素（如左侧滚动指示轨的文字）必须补上底衬或换色，不能让深底上的深色文字直接失效。
- **表单提交时清空已填内容**：提交失败必须保留用户输入。

## 6. 文案与内容反模式

- **硬编码文案**：页面里不出现中文或英文字面文案，全部走字典 `lib/i18n/dictionaries/{zh,en}.json`；内容型页面的正文走 `lib/mock/*` 的 JSON。
- **渲染后端的 `message`**：接口返回体里的 `message` 只给开发者看，UI 文案一律由 `code` 查字典得到，否则英文用户会看到中文。
- **中英混排残留**：切换语言后页面上不允许残留另一种语言（含 `aria-label`、`alt`、按钮文字、空状态文案）。
- **承诺性话术**：不写「最高赔付」「100% 理赔」「全网最低价」「限时优惠」这类无法兑现或诱导性的表述。
- **营销段落堆砌**：不写空洞的「我们致力于……赋能……」；公司介绍控制在 2–3 段，讲清做什么、怎么做、为什么可信。
- **遗漏演示声明**：首页、关于我们、页脚必须出现「演示数据」声明；关于我们页需显式说明公司信息为占位。

## 7. AI 常见问题（本项目的重点自查项）

- 忘记 `await params`：Next.js 15 起动态参数是 Promise，`const { locale, slug } = await params`。
- 在 `middleware.ts` 里拦截 `/api` 或 `/static`：matcher 必须排除，接口请求不能被改写。
- 在服务端组件里调用续期函数：会话滑动续期要重写 Cookie，只能在 Route Handler / Server Action / middleware 中做；服务端页面只读会话。
- 在需要标签的地方漏掉 `htmlFor` / `aria-describedby`：shadcn `FormField` 已经处理，脱离 `FormField` 的只读字段要显式给 `id` 与 `htmlFor`。
- 把 `FormLabel` 用在 `FormField` 之外：它会读表单字段上下文，会直接抛错。
- 金额与日期手写格式化：一律走 `lib/i18n/format.ts` 的 `Intl` 封装，并给数字加 `tabular-nums`。
- 用 `index` 当 `key`、在渲染函数里新建对象、给列表项加 `useMemo` 之外的内联函数。
- 为了「更灵活」引入没被要求的依赖、状态库、抽象层或配置项。
- 顺手重构与本次需求无关的代码，或顺手删除别人留下的死代码。
