---

## 1. 一句话视觉定位

**像一家有牌照的老牌保险公司新做的官网**——克制、可信、愿意把条款和价格摊开给你看。

判断标准：如果某个设计决策让页面更像「互联网创业公司」或「4S 店促销页」，就不做。

---

## 2. 品牌气质

| 要 | 不要 |
| --- | --- |
| 可信赖：第一眼传达「这家公司赔得起」 | 激进、博眼球、制造焦虑 |
| 稳重但不老气：有秩序感，但仍然轻快 | 银行理财产品的压抑与厚重 |
| 清晰优先：信息层级一眼可读，价格敢放大 | 把关键信息藏进插画和icon里 |
| 一点温度：暖色点睛，让人不觉得冷冰冰 | 促销式红黄轰炸 |

---

## 3. 设计关键词

| 关键词 | 意味着 | 不意味着 |
| --- | --- | --- |
| **深海军蓝** | 主色用于标题、主按钮、页脚底色等「重」位置 | 不等于把整站铺满深蓝；深色只做锚点 |
| **冷白纸感** | 页面底色是带一丝蓝的冷白（参考站 `#F8FBFE` 一档），卡片纯白微微浮起 | 不是纯白一片的苍白感，也不是灰色水泥底 |
| **大标题、小正文** | 分区标题敢用 40–70px 级别的大字，正文保持克制 | 不等于通篇大字，正文仍要细而密 |
| **暖色只做点睛** | 暖色占比 < 10%，只出现在徽标、价格强调、悬停态 | 暖色不做大面积背景，不做第二主色 |
| **信息即设计** | 价格、保额、服务内容本身构成视觉主体 | 不靠花哨的装饰图形填充版面 |
| **网格稳** | 严格对齐，卡片高度与基线一致 | 不追求错落、拼贴、不对称的编辑感 |
| **微动效** | 只有渐显与过渡两类，都在 200ms 以内 | 不要视差、不要仪式感动画 |

## 4. 参考站分析：exhibitionguard

### 4.1 实测数据（2026-09-21 抓取）

| 项目 | 参考站取值 |
| --- | --- |
| 主色（按钮 / 强调） | `#214E8E` |
| 深色标题 | `#011E40`、`#06142F` |
| 页面底色 | `#F8FBFE` |
| 绿色辅助 / 激活态 | `#74BD9C`（浅）、`#2F8F6E`（深） |
| 价格数字 | 无独立强调色，直接用主色 `#214E8E`，46px / 700 |
| 浅蓝描边 | `#C8D6EA` |
| 中性灰阶 | `#333`、`#666`、`#E0E0E0`、`#F6F6F6` |
| 字体 | `"IBM Plex Sans SC", Inter, sans-serif` |
| H1 / H2 | 69px / 700、42–48px / 700 |
| 导航 / 卡片标题 | 14px / 400、16px / 700 |

### 4.2 结构观察

- **Header**：透明叠在 Hero 图上；左侧双行 Logo（中文名 + 英文域名），中间居中导航，右侧胶囊形描边「登录」按钮。
- **Hero**：整屏展会摄影图 + 强白遮罩（照片被洗得很淡）；左对齐超大标题，**第二行换色**（深蓝 → 绿）制造节奏；下方是放大的价格数字行（「保费 低至 **145** 元起」，数字用主色 46px / 700）；双 CTA——实心深蓝主按钮 + 白底描边次按钮。
- **分区抬头**：英文小字眉标（`YOUR SHOW. OUR COVER.`，大写 + 字距拉宽）+ 大标题（两行、第二行换色）+ 居中两行副标题。
- **产品卡片**：横向布局（左方形图 + 右文字），序号眉标「01 / 现场责任」，标题 16px，一句话说明，蓝色「查看详情 →」。
- **导航辅助**：左侧竖向滚动指示轨（圆点 + 当前分区标签胶囊，激活点为绿色）；右侧悬浮工具轨（联系方式 / 微信客服 / 返回顶部）。

### 4.3 取什么

- 深蓝 + 冷白底的骨架，以及「深色只在锚点位置」的克制用法。
- 大标题两行、第二行换色制造节奏的手法。注意：换色用 `--primary` 相对 `--foreground` 的**同色相深浅对比**实现，不引入第二个色相，以遵守 §7 的「暖色 < 10%、只出现在小面积元素」约束。
- 产品卡片「左图右文 + 序号眉标」的横版结构（适合信息密度较高的卡片）。
- 分区抬头的统一模版：眉标 → 大标题 → 副标题。
- 页面级留白的尺度感。
- 左侧滚动指示轨（首页分区滚动场景同样适用）。

### 4.4 不取什么，以及为什么

| 参考站做法 | 我们的做法 | 原因 |
| --- | --- | --- |
| 主色是「深蓝 + 绿」 | 深蓝 + **暖色**点睛 | 避免视觉上像同一家公司；暖色也更贴合汽车与「保障、关怀」的语境 |
| Hero 用整屏摄影图 + 重白遮罩，文字压在图上 | 改「左文右图」分区，文字永远落在纯色区域 | 重遮罩把照片洗得发灰、Hero 整体发闷；文字与图片的对比度还会随图片内容波动 |
| 产品卡片只说名称 + 一句话 | 卡片必须带**价格与保额** | 车险用户的第一诉求是比价；参考站信息偏营销 |
| 价格强调只靠「放大字号 + 主色」，没有独立强调色 | 保留放大字号，再叠加低饱和暖橙点睛 | 价格是第一公民，值得一个更明确的视觉抓手；但暖色仍控制在 10% 以内 |
| Hero 底部自动轮播滑块 | 不做自动轮播 | 自动轮播会打断阅读，并与「微动效」原则冲突 |

## 5. 视觉层级

**每个页面的阅读顺序**（从强到弱）

1. 品牌 / 导航（吸顶 Header）
2. 页面主标题（一屏内唯一的视觉焦点）
3. 价格与保额（第二焦点，数字允许放大到接近标题级别）
4. 服务内容 / 条款说明（正文密度区）
5. 辅助操作与链接（弱化）

**制造层级只用三样东西**：字号、颜色深浅、留白。不靠阴影堆叠、不靠边框加重、不靠背景色块分区。

**硬性规则**

- 一屏之内只允许一个视觉焦点；出现两个同等重量的元素即为不合格。
- 价格数字在所在屏内必须是最大或次大的元素。
- 主按钮实心、次按钮描边或幽灵态，不允许两个实心按钮并列。
- 正文不使用纯黑；标题与正文的色深必须有明确差别。

## 6. 布局倾向

- **分区靠留白切，不靠线切**：分区之间用「大留白 + 分区抬头」区分，尽量不用分割线或色块硬切。
- **统一的分区抬头模版**：小字眉标 → 大标题 → 副标题。首页四个分区必须共享同一套模版，否则会像四个不同网站拼在一起。
- **卡片语言**：中等圆角、极轻阴影，**边框优先于阴影**（浅蓝描边），保证信息型卡片显得干净而非漂浮。
- **节奏交替**：避免连续三屏都是卡片网格；在「产品」与「指引」之间插入一段留白较大的说明性内容。
- **栅格气质**：严格的 12 列对齐感，卡片左右边缘与标题左右边缘对齐。
- **页脚**：深蓝底反白，与浅色正文区形成明确的「页面结束」信号。
- **双语排版预留**：英文文案长度通常比中文长 30%–50%，所有按钮、导航项、卡片标题都必须按英文长度预留宽度，禁止用「中文刚好放下」的宽度定稿。标题换行位置按中文节奏设定，英文允许重排。

## 7. 色彩方向

只定义**角色分工与关系**，精确色阶在 `design.md` 落 token。

| 角色 | 方向 | 使用位置 |
| --- | --- | --- |
| 主色 | 深海军蓝（明度低、饱和度中），与参考站 `#214E8E` 同族但更深 | 主按钮、标题、图标、页脚底 |
| 深色文字 | 比主色更深的近黑蓝 | 大标题 |
| 正文文字 | 中性深灰 | 段落与说明 |
| 页面底色 | 带一丝蓝的冷白 | 全站背景 |
| 卡片底 | 纯白 | 卡片、弹窗、表单 |
| 描边 | 浅蓝灰 | 卡片边框、输入框、分隔 |
| **暖色点睛** | 单一低饱和暖橙，不做第二色 | 徽标（热销/新品）、价格强调、悬停态、滚动指示轨激活点 |
| 状态色 | 独立于品牌色的一套语义色 | 订单状态：待支付 / 已生效 / 已取消 / 已失效 |

**规则**

- 暖色总占比 < 10%，且**只出现在小面积元素上**。
- 深蓝不用于长段正文。
- 状态色只表达状态，不做装饰；「已生效」用偏绿的语义色，但不能与暖色点睛混用在同一位置。
- 订单状态徽标必须同时用「颜色 + 文字」，不允许只靠颜色区分。

## 8. 字体方向

- **中文**：开源中文无衬线（思源黑体 / Noto Sans SC 一类），气质偏「公共服务」而非「秀场」。
- **英文与数字**：配一款 x-height 与中文接近的几何无衬线（Inter 一类）；数字启用等宽数字（tabular-nums），保证价格与车牌号对齐。订单号是 UUID，改用等宽字体，见 `design.md` §3.3。
- **字重纪律**：全站最多三个字重（正文 400 / 强调 600 / 标题 700）。不使用 900 级别的超粗标题。
- **价格数字**：允许单独放大到标题级，且必须用同一款字体的数字，不额外引入展示型字体。
- 不使用手写体、装饰衬线体。

> **实现注意**：当前脚手架 `app/layout.tsx` 加载的是 Geist / Geist Mono，**不含中文字形**，中文会回退到系统字体，导致中英混排的字重与 x-height 不一致。实现阶段需替换为覆盖中文的字体方案（`next/font` 加载 Noto Sans SC + Inter）。

## 9. 图像与图标方向

**摄影**

- 主题：真实用车场景——城市道路、夜间街道、停车场、车主与车、行驶中的车。
- 色温统一偏冷、低饱和，与冷白底和主色相容；避免暖黄偏色与主色打架。
- 产品卡片配图用 1:1 或 4:3 小图，同一分区内的图片风格、色调、景别必须一致。

**明确不要的图片**

- 抽象几何、电路板、光效粒子等「科技感」素材。
- 握手、击掌、假笑团队照等图库感素材。
- 3D 渲染的汽车模型大图。

**图标**

- 统一线性图标，描边粗细一致、端点圆角一致；不混用实心与线性。
- 图标只做辅助，不与标题争夺注意力。

**插画**

- 仅用于「投保指引」的流程示意，采用线稿风格；其余位置不使用插画。

## 10. 动效基调

**只允许三类动效**

1. 滚动进入渐显：时长 ≤ 200ms，位移 ≤ 12px。
2. 首页 Header Tab 的平滑滚动定位。
3. 悬停 / 聚焦过渡：时长 ≤ 150ms，只改颜色、边框、轻微位移。

**禁止**

- 视差滚动、逐字打字机、数字滚动跳表。
- 自动播放的轮播与视频背景。
- 移动端保留桌面级动效（移动端只保留颜色过渡）。

## 11. 视觉差异化

| 对比对象 | 我们的差异 |
| --- | --- |
| 参考站 exhibitionguard | 暖色点睛替代绿色；Hero 改为「左文右图」保证文字对比；产品卡片带价格与保额 |
| 国内车险官网（传统保险公司） | 不堆促销红黄、不做满屏浮动「立即报价」弹窗、不用密集表格压信息 |
| 通用 SaaS 模板站 | 有真实摄影与真实条款信息，不是「三个图标 + 一句 slogan」的空壳 |

**一句话差异点**：把「价格与保额」当成第一公民来设计，而不是当成需要被引导填表才能看到的结果。

---

## 12. 明确不追求的风格

- 科技暗黑风 / 大屏数据可视化风。
- 玻璃拟态、霓虹渐变、发光边框。
- 大面积深色主题，以及默认跟随系统开启深色模式。
- 促销式红黄配色、倒计时、限时抢购话术的视觉包装。
- 卡通插画与吉祥物。
- 极简到没有信息量的「设计师作品集风」。
- 拟物化与重度阴影。

---

## 13. 移动端视觉降级

- 大标题降字号，但保留「两行 + 第二行换色」的节奏；不允许标题压成一行小字。
- 产品卡片由横版左图右文改为纵向：上图下文，价格仍保持在卡片视觉重心。
- 右侧悬浮工具轨移除；左侧滚动指示轨在移动端改为 Header 下方的横向 Tab 高亮。
- 主按钮保持实心深蓝，次按钮降级为文字链接。
- 动效仅保留颜色过渡。

## 14. 视觉验收清单

实现阶段逐条对照，任一条不满足即视为未完成：

- [ ] 全站底色为冷白，卡片为纯白，深蓝只出现在锚点位置。
- [ ] 暖色总占比 < 10%，且只出现在小面积元素上。
- [ ] 一屏内只有一个视觉焦点；同屏没有两个实心按钮并列。
- [ ] 价格数字在所在屏内为最大或次大元素。
- [ ] 首页四个分区共用同一套抬头模版（眉标 → 大标题 → 副标题）。
- [ ] 所有导航项与按钮按英文（较长语言）长度预留，无截断、无换行溢出。
- [ ] 订单状态徽标同时使用颜色与文字。
- [ ] 全站字重不超过三种。
- [ ] 未出现第 12 节任一「不追求的风格」。
- [ ] 移动端断点下无横向滚动条，悬浮轨道已移除。
- [ ] 页面中无自动轮播、无视差、无逐字动画。
