# visual.md：长什么感觉

**回答**：整体视觉方向、品牌气质、参考与差异、明确不追求的风格。
**不回答**：具体色值与字号（design.md）、组件用法（ui-patterns.md）、页面结构（page-specs.md）。

原则：先定方向，再谈令牌。令牌是方向的落地，不是方向本身。

## 骨架

```markdown
# <产品名> 视觉方向

> 版本：v0.1｜上游：prd.md｜下游：design.md

## 1. 一句话视觉定位
## 2. 品牌气质
## 3. 设计关键词
## 4. 视觉层级
## 5. 布局倾向
## 6. 色彩方向
## 7. 字体与语气
## 8. 参考站与截图
## 9. 差异化
## 10. 明确不追求的风格
## 11. 验收清单
```

## 每节写什么

- **1 定位**：一句话，例如「专业可信的金融服务感，而不是互联网消费品的活泼感」。
- **2 品牌气质**：3–5 个形容词，每个词配一个反面说明它不是什么。
- **3 关键词**：用「是 A，不是 B」的对照式写，便于判断取舍。
- **4 视觉层级**：谁最重（价格 / 主标题 / 主行动）、谁次之、谁最轻（辅助说明、时间戳）。
  这一节直接决定后面的字号与颜色权重。
- **5 布局倾向**：信息密度、留白节奏、卡片化还是表格式、容器宽度倾向、
  首屏形态（文案主导 / 数据主导 / 图片 / 背景视频）、区块之间的呼吸感。
- **6 色彩方向**：只写方向和角色分配（主色承担什么、暖色点缀用在哪、警示色用在哪），
  具体色值留给 design.md。
- **7 字体与语气**：字族方向（无衬线 / 衬线）、字重对比策略、中英混排的处理、
  数字是否使用等宽数字。文案语气也在这里定（正式 / 亲切 / 简短）。
- **8 参考站**：逐个写 **抄什么 / 不抄什么**，并贴截图或标注具体区块。
  只写链接等于没写——照搬整站是最常见的失败。
- **9 差异化**：我们和参考站在哪几点上不同，为什么。
- **10 明确不追求**：与「追求」同等重要。列 4–8 条，例如「不追求动效炫技」「不追求暗色霓虹」。
- **11 验收清单**：可勾选。

## 首屏素材规格

首屏要放图或视频时，把规格写进第 5 节，避免后面反复返工：

- 视频：**必须静音 + 自动循环播放 + 提供兜底封面图**，并给出体积上限与压缩目标。
- 图片：给出目标显示尺寸与最大体积，注明 retina 倍率。
- 任何大素材都要写「首屏字节预算」，否则一定拖慢首屏。
- 装饰性素材必须可被无障碍忽略（空 alt / aria-hidden），不能抢占文本对比度。

## 常见漏项

- 参考站只贴链接，没写抄什么、不抄什么。
- 只有形容词，没有可判断的边界（「现代简洁」谁都能说）。
- 把色值、字号写在这里，和 design.md 出现两套值。
- 没写「明确不追求」，导致后面每个人按自己口味加东西。
- 首屏素材只有「放个视频」，没有静音、兜底、体积约束。

## 验收清单

- [ ] 设计关键词是成对的对照（是 A 不是 B）。
- [ ] 视觉层级明确到「谁最重」，能据此判断字号与颜色权重。
- [ ] 每个参考站都写了抄什么与不抄什么。
- [ ] 「明确不追求」非空且具体。
- [ ] 全文没有出现具体色值与字号（那些在 design.md）。
